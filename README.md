# Site G PROG ACADEMIE

Un seul fichier : `index.html` (HTML + CSS intégrés, aucune dépendance sauf les polices Google Fonts).

## Mettre en ligne
- Hébergement gratuit possible : Netlify Drop (glisser le dossier sur app.netlify.com/drop), GitHub Pages ou OVH / o2switch avec un nom de domaine (ex. gprog-academie.fr).
- Après la mise en ligne, compléter l'hébergeur dans « Mentions légales » (texte surligné `[... à compléter]`).

## Remplacer les illustrations par de vraies photos
La section « Le matériel que vous aurez en main » contient 3 illustrations. Pour chacune, un commentaire `<!-- PHOTO 1/2/3 -->` dans index.html indique la ligne `<img>` à mettre à la place du bloc `<svg>`.
Déposer les photos dans le dossier `images/` sous les noms : `boitier.jpg`, `faisceau-injecteurs.jpg`, `diagnostic.jpg` (format paysage 4:3 conseillé).
N'utiliser que vos propres photos ou celles d'un fabricant qui vous a donné son accord (kit média).
